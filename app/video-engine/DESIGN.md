# AIPM 工作台短片设计约定

画面以导入的真实工作台截图为主体，图片保留真实比例，以遮罩与镜头位置适配构图。界面素材表现产品外观，不伪造实时电脑操作。输出为数据驱动的可信 Remotion 模板，模型只提供分镜文字、时长、颜色与素材编号。

设计基准为 1920 × 1080 / 30fps；其他尺寸按比例缩放并留边。深蓝背景 `#080e1b`、冷白字 `#f6f8ff`、淡蓝强调 `#b7dcff`。字使用本机系统中文字体，不联网下载字体。玻璃通过一层浅透明填色、细高光边缘与背景模糊构成。品牌 P、左上 AIPM 页眉、底部进度轨道贯穿四场景。

四场景分别为品牌、任务输入、真实页面、收束。入场用阻尼弹簧完成平移与镜头稳定，截图保持轻微持续运动；文字分层进入并给出停留。音效由本机合成，在开场及分镜边界出现短促提示。没有付费音频、网络背景音乐、强制配音或原生文生视频调用。

渲染使用 Remotion 固定版本的 Chrome Headless Shell 与 PNG 截帧，关闭共享内存截图。不能替换成用户桌面版 Chrome 并行渲染；后者在 macOS 上有已记录的偶发瓦片/缺字问题，见 https://github.com/remotion-dev/remotion/issues/9473 。首次安装浏览器后，正式渲染只读取本地素材与本地编译页面。

本模板参考 `deepseek-opus-motion-skill` 的真实屏幕比例、共同视觉标识、先定时序与关键帧复审方法。它不声称复刻 Opus，不执行模型提供的代码，也不包含该上游技能完整生成任意画风、角色骨骼、多材质变形或五评委流程。上游许可证、版本与文件哈希见 `credits/`。
