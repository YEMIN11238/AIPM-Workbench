# 运行依赖与许可

此工程使用固定版本 Remotion 4.0.538（`remotion`、`@remotion/bundler`、`@remotion/renderer`、`@remotion/cli`）以及 React / ReactDOM 19.3.0。运行依赖的完整版本与完整性记录在 `package-lock.json`，在新电脑执行 `npm ci` 会安装其原始许可证。工程导出不包含 `node_modules`。

- Remotion 采用其专有许可及公司许可规则，见随附 `Remotion.LICENSE.md` 和 [官方许可说明](https://www.remotion.dev/license)。个人与组织的适用条件应按官方条款判断。
- React 和 ReactDOM 为 MIT，许可证分别见 `React.LICENSE`、`ReactDOM.LICENSE`。
- 设计方法参考项目为 MIT，许可证与固定提交出处见 `motion-design-prompt-generator.LICENSE`、`motion-design-prompt-generator.SOURCE.json`。没有拷入或运行该项目的陌生构建脚本。
