# AIPM 个人桌面工作台

中文 | [English](README.md)

## 概要

本地 macOS 工作台，用来讨论、开发和运营 AI 产品。独立的 `v2/` 界面默认打开宽敞的聊天页，需要时再进入项目和专用工具。聊天和 AI 产品开发使用已安装的 Pi Agent SDK 1.3.0 实际执行任务；Pi 能读写项目文件、运行命令、调用工作台模块，并在授权后操作支持的桌面应用。

聊天、简历检查、公司调研、视频创作、产品梳理、Blueprint、GEO 和 AI 产品开发共用已保存的 DeepSeek API Key，聊天框右下角可在 Flash 与 Pro 之间切换，初始默认 Pro。大肥鱼使用独立的模型凭证。原有产品文档、证据、Blueprint 功能、GEO 流程、开发工具包资料及历史对话仍可访问。原来的 Harness Web 与桌面应用继续作为独立产品存在。

## 开始使用

打开 `~/工作台/AIPM工作台/AIPM工作台.app`。这是加载当前源码目录的本地应用，请保留源码及已安装的运行环境。应用版本为 0.4.0，主窗口加载 [v2/index.html](v2/index.html)，独立于旧版界面外壳。

1. 打开**设置**检查统一连接，初始模型为 Pro；聊天框右下角的模型文字与小箭头可直接切换 Flash／Pro。API Key 输入框留空会保留已有密钥；只有首次配置或更换时才需要填写。
2. 在**聊天**中处理已有项目时先选择工作目录，再描述希望完成的事。未选择目录的新对话会获得独立工作区。Enter 发送，Shift+Enter 换行，⌘N 新建对话。
3. 在聊天中阅读实时回复。打开**执行记录**查看工具参数、结果和**产物**，通过**打开目录**检查真实文件。生成期间和切换对话时，当前应用会话中的未发送草稿会保留。
4. 点击**停止执行**终止工作台管理的本轮任务。出现**这一步需要你确认**时，核对具体操作，再选择**批准这次操作**或**不执行**。
5. 在**项目**中搜索和筛选各类已有项目；左侧栏可直接进入 **Agent Blueprint**、**AI 产品开发**和**视频生成**，公司调研、GEO 与产品文档位于**工具**。侧栏保留最近的 Pi 对话，专用流程页也可以点击**用 Pi 继续讨论**。

长任务默认不设整项任务的总时长截止，可随时点击**停止执行**。普通轮次最多请求模型 120 次、输出 120,000 个 Token；[水彩视频轮次](#水彩插画与角色动画)使用独立且较小的执行与费用上限。累计输入 Token 继续统计，但不再使用旧版 400,000 个累计输入与输出作为默认中断条件。Pi 在有效上下文接近约 80,000 个 Token 时自动整理历史，保留原始会话记录。执行限制触发时显示具体原因和用量，并可点击**继续执行**接着做；这不代表 API 余额用完，实际调用仍按供应商计费。单条命令和网络请求仍有各自的超时处理，避免卡住的操作一直等待。

## 切换模型

每个聊天输入区右下角显示当前 **Pro／Flash ⌄**。选择后立即保存到本机 `model.json`，其它模块同步显示同一选择，重启后仍保留。正在保存选择时，发送会等保存完成；失败保留原模型与未发送内容。进行中的任务继续用启动时的模型，下一次请求使用新选择。

Pro 对应 `deepseek-v4-pro`，Flash 对应 `deepseek-flash`。模型目录中的版本与能力见 [model-api.mjs](model-api.mjs)，供应商后续可能更新。快速视频账本按每条请求保存当时的模型价格；切换不会重新计算旧 Pro 费用或清空试做记录。大肥鱼是此前独立配置的远程账号，继续保留自己的模型凭证和后台设置。

## 第一个例子

新建聊天并选择一个空的测试文件夹，发送下面的指令：

> 在当前目录做一个本地 AI 产品想法记录页。先检查文件，再创建中文 README 和 index.html；页面可以新增、删除想法，并用浏览器 localStorage 保存。执行当前环境可用的本地检查，准确说明通过了什么，必要时启动受管理的本地预览。不要发布，也不要创建云资源。

Pi 可以通过真实本地工具检查、写入和测试文件。查看**执行记录**和**产物**，打开文件夹，并亲自核对页面效果；继续在同一聊天里提出修改。只有模型回复，不代表文件、测试或预览已经存在。

要走完整产品流程，点击左侧栏的 **AI 产品开发**创建产品，或从已有 Blueprint 产品、方案导入。可以从想法开始，也能导入 Markdown、文本、DOCX、PDF 需求文件。依次完成 PRD 体检、技术适配、后端 MVP、正式前端、部署与收尾。每阶段先核对真实产出及未决问题，再手动确认推进；Agent 不能代替你验收或填写真人样例评分。

## 简历检查

点击左侧**简历检查**打开本地集成的 [AI PM Resume Clinic](https://github.com/Innate-Labs/ai-pm-resume-clinic)。原版简历检查、编辑器与八套 PDF 模板保留；检查和优化使用工作台已保存的统一 DeepSeek 连接及当前 Flash／Pro，页面内切换模型也同步工作台。首次打开为空白草稿，不读取已有简历或项目资料，打开页面不发送模型请求。

简历草稿保存在独立的本地页面存储中，当前批改结果保留在已打开的检查页内；切换聊天、项目或工具后可以继续编辑。检查需手动触发；宿主模式每次自动优化最多执行一轮修改和一次复查。保存 PDF 会打开系统另存为窗口，取消不会生成文件。模型请求失败时保留简历原文；上游的检查标准和分数是辅助意见，修改内容仍需本人核对。

原版源码、固定提交、许可证与本地适配记录在 [integrations/ai-pm-resume-clinic-upstream](integrations/ai-pm-resume-clinic-upstream)。页面在隔离的原生显示区域运行，专用接口只提供模型状态、切换、生成和 PDF 保存；模型密钥仅由主进程使用。前端资源可离线打开，AI 检查与优化需要网络及可用的统一模型连接。更新本地集成后，重新打开 AIPM 工作台加载新入口。

## 视频创作

左侧**视频生成**只有一个创作工作区。左边是统一的视频历史，中间在同一个聊天里提出需求和修改，右侧直接播放真实成片；后台使用 Lemo、Motion、painted-animation 及原有视频工具的制作能力。新建时填写一句需求，可展开时长、画幅和风格设置，点击**开始制作**后创建项目并明确发送模型请求。继续在原项目输入修改要求，制作进度、新版本和失败原因都留在本页。

### 在工作台内播放

作品区的**成片**使用内嵌播放器，可以播放、暂停、调音量、拖动进度和全屏观看。**放大预览**会收起聊天，让画面占满作品区；点击**返回对话**继续修改。切换聊天、流式文字更新和制作进度不会反复重建正在播放的视频。选择历史版本后，预览和导出都针对该版本；新版本尚未就绪时保留上一版。

播放器只读取工作台已核对的工程媒体，通过自有 `aipm-media` 协议支持 Range 与逐段读取，不调用外部视频软件。链接不暴露可任意指定的本机路径；文件变化、符号链接、失效检查或未完成候选不会作为合格成片显示。可选封面丢失不会阻止有效视频播放。

### 制作能力与质量检查

后台结合 [Lemo Opuscar](https://github.com/lemomo-ai/lemo-opuscar) 的 59 套风格、导演与制片工具，以及 [Motion Design Prompt Generator](https://github.com/8533502-dev/deepseek-opus-motion-skill) 的设计方法。Pi 使用当前 Flash／Pro 和统一 API 创作代码，风格默认自动选择，也不会把额外付费视频服务的 Key 混入 DeepSeek 连接。历史 Motion 工程的 Remotion 源码和原产物继续保留。

制作与修改采用“源码创作 → `finish_video` 交接 → 本地制片”。模型只在需要时读取完整风格与技术资料，避免每轮混入多套构建、反复评分和渲染指令；一次少量关键帧核对后提交，不将临时文件清理作为交片条件。`finish_video` 由宿主核对当前工程、轮次及源码，接受后结束模型写稿，停止追加模型请求；未通过的提交可以修正。普通聊天不提供这个交接工具，原本正常结束的制作轮次仍兼容。执行次数或输出上限触发时，若本轮已经生成符合规格的候选影片，工作台会尝试一次本地收尾检查，不继续请求模型；检查结果替代泛泛的“继续制作”提示。没有候选影片、取消、纯讨论或供应商错误不会被当作完成。

交接成功后运行受管理的本地制片流程：保存关键帧、核对文字显示时长、渲染画面、合成声音、探测实际 MP4，并检查画面变化和非静音。只有检查通过的新版本才进入成片预览。初始化示例、只换标题、静止画面、静音或读字失败不会冒充完成；失败保留原工程和上一版本，在同一聊天解释缺项。纯讨论不会自动重复渲染，未改源码的同一版本可以复用。已生成且晚于源码与声音修改的真实影片经检查后可直接复用，避免重复渲染；较早的候选影片不会顶替更新的源码。较晚完成的本地制作会清除项目层面已经被取代的暂停或取消提示，原聊天执行记录保留；后续新失败仍显示。

这些检查验证文件与可测质量，不代替人工审美判断，也不保证 DeepSeek 达到上游为 Opus 调整的演示水准。可以在聊天里要求调整节奏、画面层级、文字或声音，再检查新片。

### 水彩插画与角色动画

在同一新建视频表单中展开**视频设置 → 画面风格**。默认的**按制作要求选择**会在新需求包含 `水彩插画`、`水彩动画` 或 `painted-animation` 时选用 painted-animation；其他水彩表述可手动选择**水彩角色动画 · painted-animation**，原有动效可选**其他动效风格**。水彩项目标题旁显示**水彩角色动画**。在已有项目的聊天里提到水彩，不会切换引擎或覆盖已创作的影片。

水彩项目实际使用本机 p5.js 与 p5.brush 绘制颜料、渗色和墨线，由统一 DeepSeek 模型创作场景代码，不调用扩散式视频 API。分镜、原曲片段、聊天、受管理制片、内嵌预览和导出都沿用同一视频项目。本地渲染不增加模型请求，创作和修改的模型请求仍计费，效果不承诺达到 Opus 演示水准。

水彩项目每个对话轮次的模型费用预算为 ¥2，最多请求模型 40 次、输出 60,000 个 Token。每次请求前按配置的高峰单价和输入／输出上界保守预留，完整有效的用量回报可降低估算；中断或用量未知时保留整笔预留。项目显示**本轮模型预算**、**已核算费用上界**和**待结算预留**，这些数字是费用估算，并非供应商实际账单。预留不足会暂停下一次请求并保存进度；额度按轮次计算，不代表整支视频总价或 API 余额。仅设置费用保护的轮次关闭隐藏的缓存预热和嵌套付费模型通道，普通聊天与其他工作台功能继续沿用原有行为。带费用保护的视频写稿关闭 DeepSeek 深度思考，避免单次额度全部耗在推理上；新读取的模型审片图片压缩至不超过 960 × 540、60,000 个 base64 字节，不降低实际影片清晰度，也不修改源图片。旧执行会话中已保存的附件保持原有大小。费用保护的视频单次回复最多使用 20,000 个输出 Token，仍受模型能力与本轮剩余额度约束。阅读时长检查会等待异步绘制；严格字面量的空文字函数记为“不适用”，不冒充通过。明确执行本地生成时可以重试取消的制作，并保留旧记录。

### 歌曲片段和分镜提示词

新建页可选择**先建音乐视频项目**，保留制作要求而不发送模型请求，再通过**歌曲与片段**或聊天旁的**♫ 歌曲**导入 MP3、WAV、M4A、FLAC。原音频复制到工程，起止时间支持分秒或秒数，勾选**将视频时长同步为歌曲片段时长**后才会调整影片规格。裁切、淡入淡出和试听均在本机执行，不上传音频、不调用模型；原曲、旧片段和历史影片保留。

音频片段通过与成片相同的受控协议在工作台内试听。开始制作前核对片段与影片时长；最终制片以宿主所选原声为准，不被模型另写的配乐替换。原曲与裁片摘要在制作前和合成前再次核对，音频选择参与版本指纹和工程快照。改变歌曲或片段后需生成新版本，旧片不冒充已换歌的结果。

Lemo 工程的**分镜**可展示、复制和编辑每镜头的提示词、时长及转场，连续镜头总长须与影片一致。保存只更新分镜资料，不自行请求模型；原快速视频的完整分镜编辑和本地渲染保留。

### 旧项目、素材和导出

## 电脑操作与权限

打开**电脑权限**，或进入**工具 → 电脑与本地工具 → 检查电脑权限**。以下两项 macOS 权限需要用户本人在**系统设置 → 隐私与安全**中分别开启：

| 权限 | 用途 |
|---|---|
| 辅助功能 / Accessibility | 读取应用提供的文字和控件，执行支持的点击、输入、按键及滚动 |
| 屏幕录制 / Screen Recording | 获取指定应用窗口的截图，供核对及本地 OCR 识别 |

点击**前往系统设置**，亲自为对应的 AIPM 工作台条目开启权限，再点**我已授权，重新检查**。部分 macOS 版本需要重新打开应用后权限才生效。Agent 不能替你授权，也不能批准自己的操作。没有电脑权限时，文件、终端和产品工具仍可使用。

电脑操作采用 macOS 原生辅助功能、应用窗口截图和本机 Vision OCR。Pro 读取辅助功能文字和 OCR 结果，不接收截图像素；Flash 支持图片输入，Pi 的图片读取与成功截图会把实际图像传给本次模型请求。可信截图会压缩为 JPEG 并限制尺寸，失败时明确显示未送图；没有图片附件不能视为已观察画面。支持应用列表与启动、界面检查、控件点击、文字输入、按键、滚动及根据截图进行的坐标操作。执行动作前需要当前目标应用的真实观察，动作后应检查实际结果。

权限显示已授权，不代表任意应用都能成功操作。自绘画布、未提供辅助功能的控件、OCR 错误、安全输入框和应用自身行为都可能限制任务。系统权限控件、钥匙串控件和工作台自己的批准控件受到限制。出现截图或批准提示，也不能证明点击、输入已经成功；应查看执行结果并核对目标应用。

2026-10-21 本机验证已完成：在新版聊天中由真实 Pi 和 Pro 创建测试文件、运行 Python 断言，并实际读取文本编辑窗口、点击正文、输入验证文字、重新读取核对及截图。AI 产品开发也已通过真实 Pi 调用保存评分维度和阶段报告，演示项目仍停在阶段 0，等待用户回答产品问题。其他应用及真实云部署需要按具体任务另行验证。
