# 工作台水彩角色动画

使用已接入工作台的完整 painted-animation 引擎。原版 Skill、指南、角色表、案例、节拍工具和渲染器保留在 `integrations/painted-animation-upstream/`。原版固定提交为 `tuzhechen2005/opus-video-skills@59744a69c7b916cfbe4c4ec84006b0c2f5e2fde1`，原始绘制引擎来自 John Heibel 的 ClaudeAnimationBase，许可证见原包。运行适配位于 `painted-runtime.mjs` 和 `painted-engine/`；不要运行上游安装、自动更新或重置脚本。

## 同一个制作项目

当前项目说明包含宿主制片项目编号、目录、当前规格、已选歌曲和已保存分镜。保持其音频、时长、比例与用户指定的角色和情绪。新建时可使用工作台的水彩角色动画制作方式；已有项目继续修改原文件。旧 Lemo、Motion 和快速视频的历史与产物保留。

项目中的 `painted/ANIMATION_GUIDE.md` 是完整引擎 API。先读当前 `painted/src/config.js` 和 `painted/src/scenes/film.js`，再按需要读取指南、原版 `references/music-video.md`、`examples/xiaozhen/` 和角色参考图。按用户要求设计角色，Clawd 是可替换的参考。角色不能只靠换文案或给旧片加整体滤镜完成。

## 创作与交接

先用简明文字确认具体分镜和情绪推进，沿用用户已经给出的制作授权。已保存的分镜提示词属于用户要求，按每镜起止时刻和总时长实现。

已有分镜时直接实现，不重复长篇规划或在保存代码前耗尽输出做推理。尽早保存可运行的场景结构，再分段补齐共用 helper 和各镜头函数；每次工具写入只覆盖合理大小的明确片段，保存后保持文件可运行，及时保留真实进展。输出优先用于场景代码与必要检查，全部镜头和声音准备完成后及时 `finish_video`。未完成时如实说明缺项；输出耗尽的推理、计划或初始化骨架都不能当作成片。

- 使用 p5.brush 的 `paint()` 和 `inkLine()` 绘制水彩填色、积色、渗边和墨线。颜色、形状、面部与手持物在镜头间保持一致；水彩来自每个对象的颜料绘制。
- 一镜头一个绘制函数，场景用 IIFE 包裹，并以 `shots([[t0, drawFn], ...])` 注册。独立对象设置 `boilSeed`，使用确定的 `hash`／`jit`。帧可乱序渲染，不能依赖前一帧，也不能定义与 p5 冲突的全局名称。
- 动作包含准备、反应和余势；脚与地面、手与伞等道具保持接触。抒情片使用克制表演、柔和色彩和稳定镜头，转场跟随歌曲与构图。
- 配置 `PROJECT.duration`、`bpm` 和 `offset` 必须匹配项目实际规格。保留原版 `core`、`clawd`、`timeline`、`karaoke`、`sheets` 与本地 vendor 资源。根 `index.html` 已桥接异步 `renderAt(t)`，不要重写桥接或改成不等待画面的截图。
- 用户歌曲由“歌曲与片段”管理，`.video-audio.json` 和 `assets/audio/` 里的原曲与片段不能覆盖。画面从所选片段的第 0 秒开始配合原声；没有精确歌词时间表时，不编造逐字字幕。没有旁白仍可保留歌曲。
- 标题或字幕按用户要求通过 `overlayHook` 绘制，并提供与实际画面一致的 `window.TEXTS(t)` 文字与像素框；没有文字时返回空数组。字体使用当前本地资源，不静默依赖远程字体。

需要核对时，通过工作台 `lemoRun` 的 `stills` 操作取得少量实际关键帧，再用图片工具观察脸部、手持物与转场。只修复已观察的具体错误，避免连续打分、反复调坐标和轮询任务。

写稿完成后调用当前视频创作工具 `finish_video`。宿主核对当前轮次和真实源码，接受后结束模型写稿，交给本地制片流程。保留普通成功结束的兼容流程。不要自己重复全片渲染、合成或清理临时文件作为交片前提。实际制片结果通过同一工作台的“成片”“分镜”“素材与文件”和“历史版本”显示。
