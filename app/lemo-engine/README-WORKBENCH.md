# AIPM Lemo runtime

This is the workbench-owned runtime copy of the pinned Lemo core and available style code. The original upstream snapshot remains unchanged in integrations/lemo-opuscar-upstream. Runtime paths and actual readiness are in runtime.json; installed Python versions are in python-installed.txt.

Node dependencies were installed from package-lock.json with lifecycle scripts disabled. Python 3.12 is installed in the short path /Users/zhangjunhao/.local/share/aipm-lemo-py because espeak-ng has a 159-byte real-path limit. The offline Kokoro pack matches the upstream size and SHA-256 in VOICE-PACK.json; Chinese and English voice smoke files were generated without model or online TTS requests.

Runtime copies of page.mjs and serve.mjs restrict browsing to the current loopback server and reject linked static assets. The runtime reading-time scanner also awaits each asynchronous render before checking TEXTS, so p5.brush frames cannot pile up in the browser. It skips rendering only for an exact whitelist of no-argument functions returning the literal empty array (`()=>[]`, or arrow/function bodies containing only `return []`). This path prints `AIPM_READABILITY {"status":"not_applicable","reason":"literal-empty-text-function","renderedFrames":0}`. It still reports NOT CHECKED and exits 2; it is never presented as a reading check pass. Dynamic TEXTS functions scan the whole film and cannot emit this receipt. Missing TEXTS/DUR and dynamic functions that return no text retain their ordinary NOT CHECKED failure. bin/ffmpeg is the already-installed full FFmpeg 7.1 arm64 binary; its license and source references are adjacent. bin/ffprobe launches the existing compositor probe with its required dylib directory restored by Node.

Keyless tests produced 2D and Three.js videos, procedural sound, subtitles and a muxed MP4 in tests/out/. JSON reports describe mechanical checks; these are not independent visual or audio quality reviews. The short transient audio smoke triggered the original muxer's low loudness warning (-28 LUFS); synthesis and muxing succeeded.

Whisper dependencies are installed but no ASR model is downloaded. Optional HDRI, instrument libraries and missing upstream demo media are not installed. Read SOURCE.json for absent demo assets; this runtime does not claim every upstream demo can be rendered unchanged. Online Edge TTS requires explicit host authorization.
